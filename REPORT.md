## 2. Контрольне запитання

**Запитання:** Які є стандартні бібліотеки Python для роботи з рядками? Які їх основні можливості?

**Відповідь:**

У стандартній бібліотеці Python є декілька потужних модулів для обробки та форматування текстових даних:

1. **`string`**:
   * Містить заздалегідь визначені текстові константи (наприклад, `string.ascii_letters`, `string.digits`, `string.punctuation`).
   * Надає клас `string.Template` для безпечного форматування рядків та підстановки змінних без використання f-strings.

2. **`re` (Regular Expressions)**:
   * Надає інструменти для пошуку за шаблоном, валідації, збору груп та заміни підстрок за допомогою регулярних виразів (`re.search()`, `re.findall()`, `re.sub()`, `re.split()`).

3. **`difflib`**:
   * Використовується для порівняння текстових послідовностей, розрахунку коефіцієнта подібності та генерації порівняльних звітів (diff).
   * Функція `get_close_matches()` дозволяє реалізовувати неточний (fuzzy) пошук слів.

4. **`textwrap`**:
   * Призначений для форматування та вирівнювання текстових блоків (розбиття тексту на рядки заданої ширини `fill()`, створення відступів `indent()`, обрізання `shorten()`).

5. **`unicodedata`**:
   * Забезпечує доступ до бази даних Unicode (нормалізація символів, отримання назв символів та визначення їх категорій).
